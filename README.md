# ToydoraGeidaiWaseiInputTool

島岡譲『総合和声』の和音記号（芸大和声の和声記号）を、GUI から組み立てて
**「トイドラ芸大和声」フォント用のキー列**を得るための単一 HTML ツールです。

> **⚠ v0.1-alpha — 仮バージョンです。**
> 記号体系・キー割り当て・スペーシングは検証途中で、今後変更される場合があります。

**公開ページ: https://kazm00th.github.io/ToydoraGeidaiWaseiInputTool/**

## 必要なもの

表示には **「トイドラ芸大和声」フォント（`ToydoraGeidaiWasei-Regular`）が
閲覧する端末にインストールされている必要があります。**

本リポジトリにフォントは**同梱していません**。CSS から
`font-family: "ToydoraGeidaiWasei"` を参照するだけなので、
フォント未導入の環境ではプレビューが正しく表示されません（その旨の警告が出ます）。

フォントは [トイドラの音楽工房](https://booth.pm/ja/items/3529220) で配布されているものです。

## できること

- 和声記号を**構成スロットに分解した GUI** から組み立てる
  （内部調の度数／和音の度数／転回指数／形体指数・付加音／準固有・同主固有・プラス・マイナス など）
- **転調表記の有無**をトグルで切り替える
- 生成された**キー列とプレビューの相互変換**（キー列を貼り付けると GUI に復元される）
- キー列をクリップボードにコピーして Word などにそのまま貼り付ける
- 不定記号（`p` □度 / `P` □度の / `l` □転 / `o` 形体指数□ / `L` 付加□）に対応

## 自動スペーシングについて

このフォントでは `/ $ Q R Y ( ~ = q w a d` などが**幅0の合成グリフ**で、
その時点のペン位置に重ねて描かれます。半角スペース1個は約 **0.035em** の
微調整単位として働くため、詰めて打つと記号どうしが重なります。

本ツールは、100px で描画したグリフのインク位置を実測して決めた
スペーシングテーブルで半角スペースを自動挿入します。度数字は字幅が
ばらばら（I:31px 〜 VII:58px）なので、必要なスペース数も**度数ごとに異なります**。

調整は**半角スペースのみ**で行い、CSS の字送り調整は使っていません。
そのため **プレビューに出ている文字列＝コピーされる文字列** です。

画面下部の「スペーシング調整」から、境界ごと・度数ごとの値を変更できます。

## 使い方

`index.html` をブラウザで開くだけです。ビルド不要・依存ライブラリなしの単一 HTML です。
